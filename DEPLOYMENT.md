# Deployment source of truth

This project is deployed from `vercel-site/` because the Vercel project is configured with that folder as its Root Directory.

For Vercel deploys, edit these files inside `vercel-site/`:

- `vercel-site/index.html`
- `vercel-site/menu.html`
- `vercel-site/commande.html`
- `vercel-site/galerie.html`
- `vercel-site/contact.html`
- `vercel-site/404.html`
- `vercel-site/css/`
- `vercel-site/js/`
- `vercel-site/fonts/`
- `vercel-site/images/`
- `vercel-site/sw.js`
- `vercel-site/vercel.json`

Avoid editing `public/` directly. It is generated by the root build and can be overwritten.

If you make changes in the root version of the site, copy them into `vercel-site/` before deploying. A quick way is:

```bash
npm run build
cp -R public/* vercel-site/
```

Vercel should be configured like this:

- Root Directory: `vercel-site`
- Build Command: leave empty or use `npm run build`
- Output Directory: leave empty

The important rule: deploy and verify the same folder. If Vercel points to `vercel-site/`, make sure the final changes are in `vercel-site/`.
